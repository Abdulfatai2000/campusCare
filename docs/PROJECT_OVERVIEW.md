# CampusCare — Project Overview

CampusCare is an independent OAU-first student services prototype supporting issue reporting, tracking, appointment requests, verified emergency contacts, and authorized campus service administration.

**Not an official Obafemi Awolowo University service.** University authorization and verified contacts are required before any official campus use.

## Users
- Students: report issues, find services, monitor owned reports, request appointments, get trusted emergency information.
- Campus administrators: triage campus-scoped reports, manage verified resources and appointments.
- Super administrators: provision institutions and manage governed access.

## Phase 0
Contains 29 renderable route shells, fixture-based UI, 32 API routes, 10 Mongoose models, and secure-by-default utilities. It does NOT include working login, database CRUD, photo upload, booking availability, notifications, or admin privileges. APIs return 501 except the readiness/health endpoint.

## Success measures
Usable issue-resolution journeys, accessibility, student feedback, permission isolation, provider verification, performance, and clear accountability.
