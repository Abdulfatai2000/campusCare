# CampusCare

CampusCare is an **independent, OAU-first pilot** for university student services: issue reporting, campus support information, appointment requests, and authorized campus administration.

> This is a community-built prototype and is **not an official OAU service**. Phase 0 creates a compilable full-stack architecture and UI previews; production workflows and authentication are deliberately not yet enabled.

See `docs/DEVELOPMENT_PHASES.md`, `docs/ARCHITECTURE.md`, and `.env.example` after the rest of the scaffold is committed.
